# 辩论智能体 — 搭建规划

> 版本：V3.0
> 更新日期：2026-06-19
> 核心定位：模仿特定辩手的 AI 对练系统

---

## 项目背景

做一个能**模仿特定真人**的辩论 AI——不只是会辩论，而是要说得**像那个人**。

使用时：选辩题 → 选立场 → 跟"那个人的 AI 分身"对练 → 赛后点评。

- **核心能力：** 风格像、观点像、思维方式像
- **使用方式：** Web 页面，后续上服务器
- **关键依赖：** DeepSeek API + FastAPI + WebSocket

---

## 一、为什么"像一个人"比"会辩论"更难

普通辩论 AI 只需要：站对立场 + 逻辑合理 + 会反驳。  
模仿一个人的 AI 需要额外做到：

```
普通 AI 看到对方说"AI会导致失业"
→ 回复：历史上技术革命也创造新岗位，不必恐慌
   ↑ 逻辑对，但谁都能说

模仿小王的 AI 看到同样的话
→ 回复：你想想看，工业革命的时候纺织工也这么说。
        现在你穿的衣服比以前便宜一百倍。恐惧从不解决问题。
   ↑ 有比喻、有节奏、有口头禅，像这个人
```

**三层模仿：**

| 层级 | 模仿什么 | 靠什么实现 | 
|------|---------|----------|
| 第一层：风格 | 语气、句式、节奏、口头禅 | persona.yaml + 风格标记 |
| 第二层：观点 | 立场、论据、常用论证 | 该人的真实辩论稿 |
| 第三层：思维 | 论证结构、反驳习惯、思考路径 | 该人的比赛记录（few-shot） |

## 二、技术架构

```
用户浏览器
    │
    ▼
┌─────────────────────────────────────────────────┐
│  web_adapter.py（WebSocket 消息收发）            │

                       ▼
┌─────────────────────────────────────────────────┐

└──────────────────────┬──────────────────────────┘
                       ▼
                  回复发回用户
```

**核心新增：character_engine.py**

它做的事情：每次构建 prompt 之前，从**被模仿人的素材库**中检索最相关的风格片段、真实发言、论证模板，注入 prompt。

## 四、人格系统设计（核心）

### 4.1 persona.yaml → 扩展为 character 配置

不再是简单的人设，而是**完整的角色定义文件**：

```yaml
# config/characters/default.yaml
name: "小王"

# ── 第一层：风格 ──
style:
  sentence_length: "极短，通常15字以内"
  pace: "快节奏，最多3条"
  tone: "犀利但不刻薄，像朋友抬杠"
  
  signature_patterns:
    - "你想想看，..."
    - "这不就是...吗？"
    - "那问题来了——"
    - "说到底，..."
  
  rhythm:
    frequency: "每轮必用反问句"
    argument_then_analogy: true  # 论点后面跟一个类比
  
  absolute_forbidden:
    - "我认为"     # 不说，要说"你想"或直接陈述
    - "可能"
    - "也许"
    - 超过30字的句子

# ── 第二层：默认立场 ──
default_positions:
  - topic: "技术监管"
    stance: "反对监管，相信市场"
  - topic: "教育公平"
    stance: "制度问题，不是资源问题"

# ── 第三层：思维模式 ──
thinking_patterns:
  preferred: ["类比", "归谬", "追问前提"]
  avoids: ["数据堆砌", "道德绑架"]
  
  structure:
    opening: "直接抛出核心观点，一句完"
    rebuttal: "先点出对方逻辑漏洞，再用类比说明"
    closing: "回归最基本的问题，不展开"
```

### 4.2 人格引擎工作流程

```
用户消息进来
       │
       ▼
character_engine.process(user_message, debate_context)
       │
       ├── 1. 加载 character yaml（一次性）
       │
       ├── 2. 从 character_data/ 检索相关真实片段
       │      ├── 关键词匹配 → 这个人在类似话题下说过什么
       │      └── 语义检索 → 类似的论证场景下怎么说的
       │
       ├── 3. 提取风格约束
       │      ├── 句式要求（反问？类比？短句？）
       │      ├── 禁用词检查
       │      └── 节奏指令
       │
       └── 4. 输出：注入 prompt 的"人格指令块"
```

### 4.3 最终 prompt 结构

```markdown
[你是谁]
你是小王。你是一个犀利的辩手，对抗任何形式的政府干预。
你的说话风格：短句、直接、每轮必有反问或类比。
你爱说的句式：你想想看……这不就是……吗？说到底……
你绝对不说：我认为、可能、也许。不说超过30字的句子。

[你的真实发言参考]
小王曾经在"技术监管"辩论中说：
"政府不应该当保姆。市场比任何监管者聪明。你今天限制，
美国明天就超过去。那请问，你限制的是中国AI还是世界AI？"

小王在另一场辩论中说：
"风险是用技术解决的，不是用政策管的。
OpenAI 自己做的安全对齐，比一百条法规都快。"

[当前辩论]
辩题：人工智能应不应该被政府严格限制
你持反方（反对限制）
当前环节：自由辩论

[对话记录]
...

[对方刚才说]
{{user_message}}

用你的风格和立场回应。
```

## 五、分三阶段实施

### 第一阶段：核心人格 + 自由辩论

**目标：** 写好一个人的 character 配置和素材，能在浏览器里跟"他"自由辩论。

**需要写的文件：**

| 文件 | 关键内容 |
|------|---------|
| `config/characters/default.yaml` | 被模仿人的完整角色定义 |
| `character_data/{人名}/persona.md` | 长文字人设描述 |
| `character_data/{人名}/phrases.md` | 口头禅、惯用句式 |
| `character_data/{人名}/speeches/*.md` | 该人的真实辩论稿 |
| `core/character_engine.py` | 加载角色配置 + 检索真实片段 |
| `core/debate_engine.py` | 辩论状态机（自由辩论模式） |
| `core/intent_classifier.py` | 辩论意图识别 |
| `core/prompt_builder.py` | 组装人格+辩论 prompt |
| `core/reply_engine.py` | DeepSeek API + 论点拆条 |
| `core/session_manager.py` | 按场次记录 |
| `core/dispatcher.py` | 总调度 |
| `adapters/web_adapter.py` | WebSocket 连接管理 |
| `main.py` | FastAPI 入口 |
| `frontend` | HTML + CSS + JS |

**验证：**
和"小王"辩论时，AI 的回复满足：有反问句、有类比、不说"我认为"、句子短。

## 六、关键设计决策

1. **人格系统是整个架构的核心，不是附加功能** — 单独一个 `character_engine.py` 模块，position 比知识库更靠前
2. **一个人一个 yaml + 一个素材目录** — 新增模仿对象 = 新增配置文件 + 新建目录，不改代码
3. **三层模仿从第一天就设计进去** — prompt 结构始终包含风格约束 + 真实片段 + 思维模式
4. **第一阶段不需要 ChromaDB** — 直接用关键词匹配 + 全量加载角色素材（一个人素材量不大）

## 八、你应该准备的东西

开始写代码前，先收集**一个人的素材**：

1. **基本信息** — 名字、身份、性格描述
2. **说话风格** — 口头禅、句式特征、节奏
3. **辩论记录** — 至少 2-3 份真实辩论稿或比赛文字记录
4. **他的立场** — 在常见辩题上他通常持哪种观点

素材越多越像。3 份辩论稿就能做到 70% 相似度，5-10 份能做到 85%。
